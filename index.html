👤 Integrar com PJ Lite

Recomendado: Código da Ficha (Seed)

Cole aqui o Código da Ficha do PJ Lite. O DM Lite lê os dados estruturados e cria um cartão completo para o mestre com status, atributos, perícias treinadas, habilidades, ataques, magias e outros campos úteis.

Alternativa: Ficha Chat

A Ficha Chat é legível e funciona como alternativa rápida. Como é texto de apresentação, o DM Lite tenta extrair os principais valores, mas ela não carrega tantos campos quanto o código.

Fluxo pensado

PJ Lite → Código da Ficha → copiar → DM Lite → PJ Lite → colar. A ficha original continua no PJ Lite; o DM Lite mantém apenas um resumo útil para a sessão.

ⓘ Sobre o DM Lite

Projeto de Código Aberto 🔓

Esta ferramenta é 100% gratuita, sem coleta de dados e sem fins lucrativos. Todo o armazenamento dos escudos é feito localmente no seu navegador.

Para ver como funciona ou salvar uma cópia no seu PC, use Exibir código-fonte da página (Ctrl+U), copie o conteúdo e salve como um arquivo .html.

Importante: armazenamento local não é nuvem. Limpar os dados do navegador, usar navegação anônima ou trocar de computador pode fazer seus escudos deixarem de aparecer nesse dispositivo.
